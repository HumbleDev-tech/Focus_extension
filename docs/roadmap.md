# Project Roadmap & Future Ideas

This document preserves the original development concepts, feature specifications, and future ideas for the extension suite.

---

## Extension 1: Libertad (YouTube Focus)

A dedicated Chrome extension for YouTube to eliminate interface distractions, with three preset focus levels plus full customization:

* **Basic**: Clutter-free watching (hides comments and end screen video cards).
* **Balanced**: Recommended balance (hides sidebar recommendations, comments, shorts, and end screens).
* **Extreme (Zen)**: Complete distraction-free mode (hides home feed, sidebar, comments, and shorts).
* **Custom Mode**: User manually selects which elements to hide (Home Feed, Comments, Sidebar, Shorts, Endscreens).
* **Return Dislikes**: Restores the public dislike counter on YouTube video pages using the official community API.

**Reference Inspiration:**

## Extension 2: Selective Bookmark Manager (Planned)

An extension for creating bookmarks manually and selectively. Allows users to choose which open tabs to bookmark from a clean selector, with a search filter to quickly find pre-defined bookmarks.

**Target Use Case:**
* Ideal when switching browsers or setting up a clean machine from scratch without importing outdated or corrupt profile data.
* Designed for users who prefer manual setup and curated bookmark organization.

**Planned Features:**
1. **Manual Selection**: Checkbox picker for currently open tabs.
2. **Bulk One-Click Save**: Batch save selected tabs into browser bookmarks.
3. **Naming Options**: Save with full title, custom name, or icon-only (minimal toolbar).
4. **Custom Folder Hierarchy**: Organize bookmarks into custom folders upon saving.
