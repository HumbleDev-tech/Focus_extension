**Extension 1** 



Una extensión para YouTube que permita ocultar elementos de la interfaz que distraen, con tres niveles de enfoque: básico, intermedio y extremo, similares a los de otras extensiones existentes.



Además, incluirá un modo personalizado donde el usuario puede elegir manualmente qué ocultar (ej. comentarios, sugerencias, shorts, barra lateral, etc.).



También integrará la función de mostrar los dislikes nuevamente en los videos.







**extension 2**



**Extensión para ayudar a crear marcadores de forma manual y selectiva. Permite al usuario elegir desde un selector cuáles páginas quiere guardar como marcadores, existira un buscador para escoger los que esten predeterminasdos dentro de la extension. Ideal para cuando se cambia de navegador y se quiere configurar todo desde cero sin importar datos antiguos.**



**Funciones:**



**Selección manual de pestañas abiertas**



**Guardado masivo de marcadores con un clic**



**Opciones para guardar con nombre, sin nombre o solo el ícono**



**Posibilidad de crear carpetas personalizadas para agrupar los marcadores**



**Pensada para quienes prefieren iniciar sesión manualmente en cada sitio y evitar errores al importar desde otros navegadores**
